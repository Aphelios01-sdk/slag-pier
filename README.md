Slag Pier is an original round-based tactical FPS in the browser: ASH vs COIL on an industrial pier, buy-time requisition, plant/defuse charge sites (Hopper / Dock), recoil gunplay, smokes and flares, and bot teammates that push and hold. Built with vendored three.js 0.187 for make.fun's threejs-fps-02 bounty.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080
